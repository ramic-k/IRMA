# SHA256 content-address manifest for the committed reference
# artifacts (tapes, vendored phonon models, frozen cross-code references,
# reference dumps).
#
# Each pinned test ("IRMA output == reference") is only as trustworthy as
# its reference. Git already surfaces any change to these blobs as a reviewable
# diff; this manifest adds an *active* assertion (test_reference_manifest.py)
# so a silently re-gzipped, truncated, or swapped reference fails loudly with a
# named hash mismatch instead of a mysterious downstream byte diff or an
# inscrutable pin mismatch. It also documents the exact bytes behind the
# README agreement figures.
#
# Format: "<sha256>  <path-relative-to-tests/>" (two spaces, `shasum -a 256`
# compatible). To re-pin after an intentional reference change, regenerate with:
#   cd tests && shasum -a 256 njoy_minitape_references/*.endf.gz \
#       native_LEAPR_NJOY_ENDF_validation/leapr_decks/*.endf.gz \
#       mode2_euphonic_n1_validation/{graphite,beryllium}/{phonopy.yaml,FORCE_CONSTANTS,irma_mode2_n1.input.template,euphonic_n1_reference.npz} \
#       chopper_reference/pychop_reference.json
